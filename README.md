## 🚀 Featured Projects

### 🤖 CortexAI — Multi-Agent AI SaaS Platform

> A ChatGPT/Gemini-style platform with 8 specialized AI agents, a Node.js microservices backend, and a full RAG pipeline.

| | |
|:---|:---|
| 🏗️ **Stack** | React · Redux · Node.js Microservices · MongoDB · LangChain/LangGraph |
| 🧠 **Agents** | Chat · Search · Coding · Image · PDF · PPT · PDF-RAG · Image Analyzer |
| ⚙️ **Architecture** | Auth, Chat, Agent & Billing services behind a single API Gateway |
| 🔍 **RAG** | PDF chunking → embeddings → **Qdrant** vector search for grounded Q&A |
| ⚡ **Caching** | **Redis (Upstash)** for session caching, memory & per-agent rate limiting |
| 💳 **Billing** | Credit-based, tiered access via **Razorpay**, **Firebase Auth** (server-verified) |
